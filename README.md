# dreamly-site

Public pages for the Dreamly iOS app (served by GitHub Pages):

| Page | URL |
|------|-----|
| Home (Marketing URL): story, how it works, screenshots, tip links | https://ogolovch.github.io/dreamly-site/ |
| Privacy Policy | https://ogolovch.github.io/dreamly-site/privacy.html |
| Support | https://ogolovch.github.io/dreamly-site/support.html |

Source of truth is `Dreamly-web/` in the app repo — edit there and copy here.
`img/` holds web-sized copies of the App Store screenshots. `.nojekyll` makes Pages serve the
files as plain HTML (skips the Jekyll build).
Enable once: **Settings ▸ Pages ▸ Deploy from a branch ▸ `main` / `(root)`**.
